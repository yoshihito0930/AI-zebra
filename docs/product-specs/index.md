# Product Specs — v1

## 誰のためのものか

- **お客様**: スタジオを借りて撮影したい人。HPでスタジオを知り、空き状況を見て予約する
- **スタジオ管理者**: 予約を確認・承認し、お客様に連絡する。利用者は数人

## v1 のスコープ

### HP（apps/site-zebra）
- スタジオの紹介、設備・機材、料金、アクセス、お問い合わせ
- 予約ウィジェットを埋め込み、空き状況を表示する
- 現行HPのURLから新URLへのリダイレクト

### 予約ウィジェット（packages/booking-widget）
- 日付ごとの空き状況をカレンダーで表示する
- 状態：空きあり / 空きなし / 読み込み中 / エラー
- 予約申込フォームへの導線

### 予約API（apps/api）
- 公開：空き状況の取得、予約の申込
- 管理：予約の一覧・詳細・承認・変更・取消、確認メールの下書きと送信

### 管理画面（apps/admin）
- ログイン（スタッフのみ）
- 予約一覧（日付・状態で絞り込み）、詳細、承認・変更・取消
- 確認メールを確認してから送信する

## v1 でやらないこと

- 複数スタジオ（マルチテナント）対応
- オンライン決済
- AIによるメール文面の自動作成
- お客様のアカウント登録・ログイン（会員とゲストの区別はしない）

## リリースの進め方

1. 本番構成に非公開でデプロイし続ける（ベーシック認証など）
2. 新HPを公開する。予約は既存の手段に誘導する
3. 期間をあけて、機能フラグで予約ウィジェットを有効にする

HPの公開と予約受付の開始は同じ日にしない。
