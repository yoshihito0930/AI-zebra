# デザインの方向性

デザインの方向性は、HP のリポジトリ [zebra](https://github.com/yoshihito0930/zebra) の設計書 `studio-website/astro/docs/design-system.md`（Claude Design から作った「新ビジュアルシステム設計書」）とする（ユーザーの判断。2026-11-28）。色・文字・余白などのデザイントークンと部品の決まりは、そちらが正しい。このファイルには写さない（2か所で食い違わないようにするため）。

## このリポジトリでの扱い

- **予約ウィジェット**（packages/booking-widget）：HP の予約ページに載るので、HP の設計書に合わせる。色・文字などは、HP から設定（CSS の変数など）で渡せるようにし、ウィジェットの中にトークンの値を直接書かない。渡し方は [widget-embed.md](design-docs/widget-embed.md)（これから書く）
- **管理画面**（apps/admin）：スタッフだけが使う道具なので、HP と同じ色と文字にそろえる程度にする。一覧の見やすさ・ボタンの配置など、使いやすさを優先する
- **apps/site-zebra**：ウィジェットを手元で試すためのページ。見た目は作らない

## 確かめ方

- デザインは、HP の検証用ドメイン `https://studiozebra-test.xyz/` で確かめる
- 設計書が変わったら、ウィジェットに渡す設定の名前が変わっていないかを確かめる
