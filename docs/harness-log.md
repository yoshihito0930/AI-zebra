# Harness Log

エージェントが詰まったこと、足りなかったもの、それに対してリポジトリに足したものの記録。
AIを主軸にした開発の試行錯誤そのものを、ここに残す。

## 書き方

```
### YYYY-MM-DD 短いタイトル
- 起きたこと：
- 足りなかったもの：情報 / ツール / 制約 / その他
- 足したもの：（ドキュメント、lint、テスト、スクリプトなど。PRへのリンク）
```

### 2026-10-11 仕様インタビュー ステップ1（予約ルール）

- 足したもの：booking.md の用語表に「承認待ち」「本予約」「第二キープ」「本予約の境界」を追加し、用語を改めた理由を書いた
