# Harness Log

エージェントが詰まったこと、足りなかったもの、それに対してリポジトリに足したものの記録。
AIを主軸にした開発の試行錯誤そのものを、ここに残す。

## 書き方

```
### YYYY-MM-DD 短いタイトル
- 起きたこと：
- 足りなかったもの：情報 / ツール / 制約 / その他
- 足したもの：（ドキュメント、lint、テスト、スクリプトなど。PRへのリンク）
```
