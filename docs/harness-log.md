# Harness Log

エージェントが詰まったこと、足りなかったもの、それに対してリポジトリに足したものの記録。
AIを主軸にした開発の試行錯誤そのものを、ここに残す。

## 書き方

```
### YYYY-MM-DD 短いタイトル
- 起きたこと：
- 足りなかったもの：情報 / ツール / 制約 / その他
- 足したもの：（ドキュメント、lint、テスト、スクリプトなど。PRへのリンク）
```

### 2026-10-17 最初の1周のふり返り（フックが外れた件と誤検知）
- 起きたこと：2つあった。1つは、2026-10-15 に VSCode 拡張（Claude Code 2.1.296）のセッションで、テスト担当・実装担当のフックが一度も動かず、禁止の操作がすべて通ったこと。フォルダーが未信頼で、未信頼のフォルダーのエージェント定義のフックを黙って飛ばしていた（`--debug hooks` で確認。CLI 2.1.175 では未信頼でも動いた）。信頼を承認して立ち上げ直したら動いた。もう1つは、1周の間にガードの誤検知が4回あったこと。実装担当の2回は上の項のとおり。テスト担当は、`git add <スタブ> … | tail -2` が止まり（読むコマンドとパスが、コマンドの別々の部分にあっても止めていた）、スクラッチパッドへの PR 本文の書き込みも止まった（リポジトリの外を一律に止めていた）
- 足りなかったもの：ツール（フックが外れたことに気づく仕組みがない。ガードがコマンドを部分に分けずに判定していた）

- 次への改善：新しいセッションや Claude Code の更新のあとは、フックが黙って外れることを前提にする。エージェントの自己確認の結果を、最初の報告で見る
